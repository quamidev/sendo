## Events (sendo.on) [#events]

`sendo.on(event, handler)` returns an unsubscribe function. Handlers run one after another in the background pipeline; a throwing handler is logged and the pipeline goes on.

| ---------------------- | ---------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |

| `status`               | `{ message, status, error? }`                              | A delivery status moved an outbound message forward (sent → delivered → read, or failed).             |
| `handoff`              | `{ conversation, contact, account, reason, assignees }`    | A conversation was handed to humans.                                                                  |

## Sending (sendo.send) [#send]

```ts title="signatures"
sendo.send.text(to, body, { account?, tenant?, previewUrl?, replyTo? }): Promise<Message>
sendo.send.media(to, { type, url? | file? | id?, mimeType?, caption?, filename? }, { account?, tenant?, replyTo? })
sendo.send.buttons(to, { body, buttons: { id, title }[] /* ≤ 3 */, header?, footer? }, { account?, tenant?, replyTo? })
sendo.send.list(to, { body, button, sections, header?, footer? }, { account?, tenant?, replyTo? })
sendo.send.template(to, name, { language, variables?, headerMedia?, buttons?, account?, tenant?, replyTo? })
sendo.send.markRead(messageId): Promise<void>
```

Every send:

1. normalizes the number to E.164 (`InvalidPhoneError`);
2. resolves the account: the `account` option, else the `tenant`'s default (or only) number, else the only active account; `AmbiguousAccountError` when that is not one number ([resolution order](/docs/numbers-and-tenants#resolution));
3. gets or creates the contact and the conversation;
4. checks the 24-hour window, except for templates (`WindowClosedError`, before any write or Meta call);
5. inserts a `sendo_messages` row with status `pending` (sender `system`);
6. calls Meta (file media is uploaded first);
7. stores the Meta id and status `sent`, or `failed` with the error and rethrows.

<Callout>

Templates are read from `sendo_templates`, not from Meta: call `sendo.templates.sync()` after creating or editing templates, or `send.template` throws `TemplateNotFoundError`. A wrong number of variables throws `TemplateVariablesError`. Media is checked against Meta’s limits (image 5 MB, audio/video 16 MB, document 100 MB, sticker 500 KB) before upload.

## reply [#reply]

The `reply` in the `message` event is bound to the conversation and stores sends with that sender: `text(body, opts?)`, `media(media, opts?)`, `buttons(input, opts?)`, `list(input, opts?)`, `template(name, opts)`, `react(emoji, messageId?)` (`""` removes the reaction) and `markRead(messageId?)`. Both default to the inbound message.

## sendo.conversations [#conversations]

<Sample file="templates-conversations.ts" region="conversations" title="ts" />

- `handoff(id, { reason, to?, message?, by? })`: status `human`, reason stored, `resolveHandoffTargets` called (one assignee → `assignedTo`), the handoff message sent, `handoff` event emitted.
- `returnToAgent(id)` clears `assignedTo` and `handoffReason`; `close(id)` closes it. A new inbound message reopens a closed conversation with status `agent`.
- `assign(id, userId)` also moves the conversation to `human`; `assign(id, null)` only unassigns.
- `pauseAgent(id, paused, { by? })` stops (or resumes) the agent on one conversation; on resume it doesn't answer what arrived during the pause. Emits `conversation.agent_paused`.
- `by` (default `"system"`) shows up in the `conversation.status`, `conversation.assigned` and `conversation.agent_paused` events and in the thread's system line.

## sendo.inbox [#inbox]

Server-side operations behind the inbox server actions. Every method takes `{ actor }` from `sendo.actor(userId, tenantId)` and enforces the role matrix ([Team inbox](/docs/team-inbox#roles)): another tenant's conversation is `RecordNotFoundError`, a conversation or action the actor isn't allowed is `ForbiddenError`. A missing or forged actor (no user id, unknown or `null` role) is `ForbiddenError` with `role: null` in every `{ actor }` API, and an `accountId` filter that isn't a number of the actor's tenant is `AccountNotFoundError`.

`list` and `count` leave out the conversations of disconnected numbers unless the query has `includeInactiveAccounts: true`, that number's `accountId` or a non-blank `search`.

| Method                                                                                                | Returns                   | Notes                                                                                                                  |
| ----------------------------------------------------------------------------------------------------- | ------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `list({ actor, status?, mine?, assignedTo?, queue?, tagIds?, accountId?, search?, cursor?, limit? })` | `Page<InboxConversation>` | Agents only get what they may see. Most recent activity first. Limit 30, max 100. `count(query)` counts them.          |
| `get(id, { actor })`                                                                                  | `InboxConversation`       | One conversation.                                                                                                      |
| `thread(id, { actor, cursor?, limit? })`                                                              | `Page<InboxMessage>`      | Newest first, notes, system lines and drafts included. Media URLs signed for 300 s. Limit 50, max 100.                 |
| `reply(id, payload, { actor })`                                                                       | `InboxMessage`            | Step-in: sender human, status unchanged, pending draft discarded. WindowClosedError outside the window.                |
| `note(id, text, { actor })`                                                                           | `InboxMessage`            | Internal note, never sent.                                                                                             |
| `take` / `returnToAgent` / `close(id, { actor })`                                                     | `InboxConversation`       | Take assigns the actor and moves to human.                                                                             |
| `assign(id, userId \| null, { actor })`                                                               | `InboxConversation`       | Anyone but the actor needs `conversations.reassign`.                                                                   |
| `pauseAgent(id, paused, { actor })`                                                                   | `InboxConversation`       | Needs `conversations.pause_agent`.                                                                                     |
| `approveDraft(messageId, { actor, text? })` / `discardDraft(messageId, { actor })`                    | `InboxMessage` / `void`   | WindowClosedError when the window closed.                                                                              |

| `tags.add` / `tags.remove(id, tagId, { actor })`                                                      | `InboxTag[]`              | The conversation's tags afterwards.                                                                                    |

`InboxConversation` adds `window`, `contact.displayName`, `lastMessagePreview`, `channel`, `source`, `queue`, `assignee`, `handoff { reason, by, at }`, `agentPaused` / `agentPausedOn`, `hasPendingDraft`, `accountActive` and `tags`. `InboxMessage` adds `internal`, `systemLine` (`{ kind, event, by, params }`, see [System events](/docs/team-inbox#system-events)), `draft`, `handoffAfterDraft`, `approvedBy`, `edited`, `origin`, `source`, `transcription` (`{ model, ms, error }` for transcribed or failed voice notes, else `null`), and `tokensIn` / `tokensOut` / `costCents` (admins only). A disconnected number makes `reply`, `note` and `approveDraft` throw `AccountStateError` (`ACCOUNT_STATE`).

## Broadcasts and opt-in [#broadcasts]

`sendo.broadcasts` sends one APPROVED template to many contacts. Every method takes `{ actor }` and needs `broadcasts.manage` (admins); another tenant's broadcast is `RecordNotFoundError`.

- `preview({ actor, template, language, recipients, variables?, account?, ratePerMinute? })` returns `{ total, eligible, skipped: { no_opt_in, opted_out, invalid_phone }, category, ratePerMinute, estimatedMinutes }` and writes nothing.
- `create(sameInput)` stores a `queued` broadcast. Recipients are contact ids, `{ phone }` (upserted as a contact) or `{ contactId | phone, variables }`. MARKETING templates go only to contacts with `marketingOptIn = true`; UTILITY and AUTHENTICATION go to everyone who hasn't explicitly opted out. Ineligible recipients are stored `skipped` with the reason. `ratePerMinute` defaults to 60.
- `get(id)` adds `counts` per recipient status, `recipients(id, { status?, cursor?, limit? })` pages the per-recipient results, `list({ cursor?, limit? })` is newest first, and `cancel(id)` turns pending recipients into `cancelled`.
- `sendo.maintenance.tick()` sends up to `ratePerMinute` recipients per broadcast and minute. Status webhooks update each recipient. Meta 131042 pauses the broadcast (`pauseReason: "billing"`, number `billingReady = false`) until billing is ready again; a rate limit (130429) leaves recipients `pending` for the next tick. Broadcast messages never move a conversation to `human` or run the agent; replies land in the normal conversation.
- `sendo.contacts.setOptIn(contactId, optIn, { source? })` records an explicit decision (`marketingOptIn`, `optInAt = now`) and emits `contact.opt_in`. An inbound message that is exactly an `optOut` keyword (trimmed, case and accents ignored) opts the contact out, sends the confirmation inside the 24-hour window and skips the agent turn.

## Agents (sendo.agent) [#agents]

`sendo.agent(definition)` registers an agent and returns `{ name, remove() }`. It answers inbound messages in conversations whose status is `agent` on the accounts it matches. Only one agent may match an account.

| Field                                                                | Notes                                                                                                                                                                |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`                                                               | Unique; stored as senderRef of the agent's messages.                                                                                                                 |
| `accounts?`                                                          | Account ids / phone number ids, or `(account) => boolean`. Default: all.                                                                                             |
| `tenants?`                                                           | Tenant ids (`null` = no tenant) or `(tenantId) => boolean`. ANDed with `accounts`. Default: all. See [one agent for many tenants](/docs/numbers-and-tenants#agents). |
| `mode?`                                                              | `"auto"` or `"draft"`; the number's `agentMode` wins. Default `"auto"`.                                                                                              |
| `model`                                                              | Gateway id string ("openai/gpt-5-mini") or an AI SDK LanguageModel.                                                                                                  |
| `instructions`                                                       | string or `({ account, contact, conversation, sendo }) => string \| Promise<string>`.                                                                                |
| `tools?`                                                             | `{ [name]: { description?, input: zod schema, run(ctx) } }`. Use agentTool() for typed input.                                                                        |
| `handoff?`                                                           | `{ when, to, message? }` adds the `transferir_a_humano({ motivo })` tool.                                                                                            |
| `historyLimit? / maxStepsPerTurn? / maxMessagesPerMinutePerContact?` | Default agentDefaults (20 / 5 / 10).                                                                                                                                 |
| `fallbackMessage?`                                                   | Sent when the model or a turn fails. Default: nothing.                                                                                                               |
| `vision?`                                                            | Default true: images go to the model as image parts; false describes them in text.                                                                                   |
| `timezone?`                                                          | IANA zone for the date in the system prompt. Default: the account's.                                                                                                 |
| `pricing?`                                                           | `{ inputPerMTok, outputPerMTok }` in USD, for `costCents` when the provider reports no cost. See [usage and cost](/docs/team-inbox#cost).                            |

<Sample file="agents.ts" region="tool" title="ts" />

<Sample file="agents.ts" region="agent" title="ts" />

One turn, per conversation:

1. Takes the `conv:<id>` lock (60 s); if another turn holds it, that turn picks up the new message. With the lock held, skips the turn when the conversation or its number is paused (`agentPaused`) or a rule holds the agent; the message is still stored. A pause set during a turn lets that turn finish.
2. Skips the turn when the contact sent more than `maxMessagesPerMinutePerContact` messages in the last minute (messages are still stored).
3. Builds the system prompt in English (instructions, handoff clause, an instruction to reply in the contact's language, contact name / phone / `appRef`, current date and time) and the last `historyLimit` messages of this conversation only.
4. Runs `generateText` with `stopWhen: stepCountIs(maxStepsPerTurn)`. Tool input is validated with zod before `run`; each tool receives `{ input, contact, conversation, account, sendo }`.
5. Sends the final text as sender `agent` (or stores it as a draft in draft mode) with the turn's tokens and cost; tool calls and results go to `sendo_messages.metadata`, never to the user. Notes, system lines and drafts are never part of the model's history.
6. Loops while new inbound messages arrived (at most 3 turns), then releases the lock. On errors: logs, sends `fallbackMessage` if set, never leaves the lock held.

When the model calls `transferir_a_humano`, Sendo runs `sendo.conversations.handoff` (by `agent:<name>`) and the agent stays silent until the conversation returns to `agent`.

## Adapters [#adapters]

All storage goes through a `SendoAdapter`. Two ship with the package; both pass the same contract suite.

### supabaseAdapter [#adapter-supabase]

## Media storage (MediaStore) [#media-store]

Inbound media (images, voice notes, documents) is downloaded from Meta and stored through a `MediaStore`. The same store signs the URLs `sendo.inbox.thread` returns (300 s), feeds images to agents with `vision`, deletes the objects on `sendo.accounts.purge`, and is what `sendo doctor` checks.

```ts
interface MediaStore {
  put(path: string, bytes: Uint8Array, mimeType: string): Promise<void>;
  get(path: string): Promise<Uint8Array | null>; // null when missing
  signedUrl(path: string, ttlSeconds: number): Promise<string>;
  delete(paths: string[]): Promise<void>; // missing paths are ignored
  exists?(): Promise<boolean>; // doctor's bucket check
}
```

Which store is used: `createSendo({ media })` if set, else the adapter's default `storage` (`supabaseAdapter` → `supabaseStorage` on its `storageBucket`; `memoryAdapter` → an in-memory map). With neither, inbound media is stored as `failed`, an error is logged and doctor fails with a `config` fix.

- **`supabaseStorage({ client, bucket, signedUrlTtlSec? })`** from `@quami/sendo/storage/supabase`: a private Supabase Storage bucket with the service-role client. It's what `supabaseAdapter` uses, so you only need it to pair Supabase Storage with another adapter.
- **`s3Storage({ client, bucket, signedUrlTtlSec? })`** from `@quami/sendo/storage/s3`: AWS S3, Cloudflare R2, MinIO and other S3-compatible stores. Install the optional peers `@aws-sdk/client-s3` and `@aws-sdk/s3-request-presigner`. Signed URLs are SigV4 presigned `GetObject` URLs (TTL capped at 7 days); deletes are batched 1000 keys per `DeleteObjects`. Failures are `S3StorageError` (`operation`, `code`, `status`). The credentials need `s3:PutObject`, `s3:GetObject`, `s3:DeleteObject` and, for doctor, `s3:ListBucket` (HeadBucket).

```ts title="lib/sendo.ts"
import { S3Client } from "@aws-sdk/client-s3";
import { s3Storage } from "@quami/sendo/storage/s3";

export const media = s3Storage({
  client: new S3Client({
    region: "auto",
    endpoint: process.env.S3_ENDPOINT, // e.g. https://<account>.r2.cloudflarestorage.com; omit for AWS
    credentials: {
      accessKeyId: process.env.S3_ACCESS_KEY_ID!,
      secretAccessKey: process.env.S3_SECRET_ACCESS_KEY!,
    },
  }),
  bucket: process.env.S3_BUCKET ?? "sendo-media",
});

export const sendo = createSendo({ adapter, media /* , ... */ });
```

Keep the bucket private: the inbox only ever shows signed URLs. Some S3-compatible stores reject the CRC32 checksums recent AWS SDK versions send by default; if uploads fail with a checksum error, pass `requestChecksumCalculation: "WHEN_REQUIRED"` to the `S3Client`.

For `sendo doctor --config <module>` and `sendo mcp`, export `media` next to `adapter` from the module so doctor checks that bucket. A custom store should pass `runMediaStoreContract(name, () => store)` from `@quami/sendo/adapters/contract`.
