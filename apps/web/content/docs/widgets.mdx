A conversation that starts from a sign at the gate, a link on an invoice or a button on your website should say so. Sendo builds a WhatsApp click-to-chat link whose prefilled message ends with a short visible code, like `[#garita]`. When a contact sends that message, the new conversation is tagged with the source, and you can count conversations per source.

## Create a link [#create]

`sendo.links.create({ account?, tenant?, text?, source })` returns `{ url, code, phone, text }`. It picks the number the same way `send.*` does (an explicit `account`, else the tenant’s default number), reads it, and writes nothing.

<Sample file="widgets.ts" region="create" title="ts" />

- `source` must match `^[a-z0-9-]{1,32}$` (lowercase letters, digits and `-`). Anything else throws `INVALID_PAYLOAD`.
- The URL is `https://wa.me/<digits>?text=<text + " [#source]">`, percent-encoded. Without `text` the message is just the code.
- The contact can edit the message before sending it. If they delete the code, the conversation is simply “direct”.

## How attribution works [#attribution]

- The pipeline reads a trailing `[#code]` from the **first inbound message of a new or reopened conversation** only. It sets `conversation.source` and `message.metadata.source`. A code in a later message is ignored.
- The stored message keeps the full text. The AI agent gets the text without the code, and the inbox shows it without the code plus an “Origen: garita” chip.
- A Click-to-WhatsApp ad sets `source = "ad:<ad id>"` from Meta’s `referral`. With neither, `source` is `null` (direct).

## Count conversations per source [#sources]

<Sample file="widgets.ts" region="sources" title="ts" />

Sorted by count, most first, ties by name, `null` (direct) last among equals. It needs an actor with `numbers.manage` (admins, see the roles table in the inbox docs) and throws `FORBIDDEN` otherwise. Pass `account` to count a single number, and `from` / `to` to limit by when the conversation was created.

## The `sendo-widgets` registry item [#registry]

```shell
npx shadcn@latest add @sendo/sendo-widgets
```

It adds:

- **The “Enlaces” screen** at `/inbox/links` (`app/(protected)/inbox/links`): pick a number, write the message and the source, then copy the link, download the QR as PNG or SVG, and copy the chat bubble snippet. Below it, the sources table with conversation counts. Admins only.
- **`<SendoQrCode value label />`** (`components/sendo/widgets/qr-code.tsx`): error correction H (Q when the message makes the code too dense, never lower), a 4-module quiet zone, always black on white so phones read it in dark mode too. The PNG and SVG are generated in the browser; no external QR service sees your links. It uses `qrcode-generator`, a dependency of the item, not of `@quami/sendo`.
- **`<SendoChatBubble />`** (`components/sendo/widgets/chat-bubble.tsx`) for your public site.

Before using the screen, implement `requireUser()` in `app/(protected)/inbox/links/links-config.ts` (it throws until you do) and configure `resolveRole` in `createSendo`.

## Chat bubble [#chat-bubble]

A floating button that opens WhatsApp with the message ready. It’s a plain link, so it works in Server and Client Components and needs no client JavaScript. It has hover and press states, and with `prefers-reduced-motion` the press doesn’t scale.

```tsx title="app/layout.tsx"
import { SendoChatBubble } from "@/components/sendo/widgets/chat-bubble";

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="es">
      <body>
        {children}
        <SendoChatBubble phone="+502 5555 1234" text="Hola, quiero información" source="web" />
      </body>
    </html>
  );
}
```

| Prop       | Type                              | Notes                                                                            |
| ---------- | --------------------------------- | -------------------------------------------------------------------------------- |
| `phone`    | `string`                          | Any format; only the digits are used. Renders nothing when it isn’t 7–15 digits. |
| `text`     | `string?`                         | Prefilled message.                                                               |
| `source`   | `string?`                         | Appended as `[#source]`.                                                         |
| `href`     | `string?`                         | A link from `sendo.links.create` (overrides `phone`, `text`, `source`).          |
| `position` | `"bottom-right" \| "bottom-left"` | Default `bottom-right`.                                                          |
| `label`    | `string?`                         | Accessible name and tooltip. Default “Escríbenos por WhatsApp”.                  |

To pick the number by account or tenant instead of by phone, build the link on the server and pass `href={link.url}`.

## Without React [#plain-link]

The bubble is a convenience. Any site, email or PDF can use the plain link, and attribution works the same:

```html
<a href="https://wa.me/50255551234?text=Hola%2C%20quiero%20informaci%C3%B3n%20%5B%23web%5D">
  Escríbenos por WhatsApp
</a>
```

Encode the whole message with `encodeURIComponent` (`[` is `%5B`, `#` is `%23`, `]` is `%5D`). There is no non-React embed script for the bubble.

## Why not Instagram or Messenger links yet [#other-channels]

Instagram (`ig.me`) and Messenger (`m.me`) have their own click-to-chat links, and Sendo’s schema already has a `channel` column for them. But only WhatsApp messages are parsed and answered today. A link to a channel whose messages never reach your inbox would be a broken promise, so the link builder is WhatsApp-only and will add `ig.me` / `m.me` when those channels ship.
